本页解答使用中的常见问题。扩展完全免费，不收集用户数据。

快速跳转： 需要登录吗 清晰度 下载失败 处理较慢 分 P 与合集 文件较大

需要登录 B 站吗？

扩展不强制登录。未登录时通常只能下较低清晰度；登录后可能更高（视视频与账号而定）。

清晰度偏少时：登录 B 站 → 刷新视频页 → 再打开下载面板。

为什么最高只有 720P？

  • 可选清晰度由 B 站与您的账号决定
  • 未登录或非大会员时，高清可能不可用
  • 部分视频本身就没有更高清晰度

下载失败怎么办？

按顺序试这三步即可：

  1. 先播放视频 5～10 秒，再点下载
  2. 改选 720P 后重试
  3. 刷新页面（F5），或在扩展管理页「重新加载」后再试

仍失败时，可在下载面板查看失败阶段，使用「复制诊断」保留排查信息。诊断分享前请检查内容。

进度停在「合并音视频」很久？

高清文件需要在您电脑上合成，体积越大耗时越久。合成默认在专用 Worker 中分段处理，面板应仍可关闭，任务也可点击「取消」。

若长时间没有变化，请先取消任务，再改选 720P 重试；不要反复点击开始下载。

分 P 和右侧「合集列表」有什么区别？

  • 分 P：同一个视频里的多段（P1、P2、P3…）。面板会出现分 P 按钮，并可「队列下载全部」。
  • 视频合集：播放器右侧的一组视频。面板提供「列表下载」时，可勾选或全选已加载的合集条目，按设置并发下载。

普通单集视频可直接点「开始下载」。

分 P 队列怎么用？

  • 开始下载：只下当前选中的那一 P
  • 队列下载全部：按 P1 → P2 → … 安排任务，同时下载 1–5 项（默认 3），每 P 一个文件

提示文件较大？

1080P 或体积较大的视频没有固定大小上限，只要片源可用就会尝试下载。但合成会占用较多内存与 CPU；电脑性能有限时建议一次只下载一个大文件，合成期间可随时取消。

支持哪些页面？

支持普通视频、列表与合集、UP 主空间投稿，以及当前账号可访问的官方剧集。官方剧集的可选视频和音频以 B 站返回为准，受试看、地区或内容保护限制的媒体不可下载。
