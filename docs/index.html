B站视频下载助手 · 隐私政策

最后更新：2026-11-20 · 版本 0.0.1 · 常见问题

本政策说明「B站视频下载助手」如何处理信息。

1. 我们收集哪些数据

开发者不收集、不接收、不出售您的个人数据。下载记录、设置和未完成任务检查点仅保存在您的浏览器本地，不发送给开发者。

  • 不收集姓名、邮箱、账号密码
  • 不收集浏览历史并发送到第三方服务器
  • 不使用分析/追踪 SDK
  • 不包含广告

2. 本地处理说明

本扩展在支持的 B 站视频、列表、合集和 UP 主空间页面运行，向 B 站及其媒体 CDN 请求视频信息与媒体，MP4 合并在您的浏览器本地完成。Chrome/Edge 下载视频或批量内容时由您选择保存文件夹；单独封面使用浏览器原生保存流程。

本地数据包括下载历史（普通与无痕各保留最近 50 条）、文件名与语言主题等偏好、未完成列表任务（旧版本还可能保留悬浮按钮位置）。新产生的普通与无痕历史分别保存，可在对应窗口的弹窗清空；旧版本的历史无法自动区分来源，仍保留在原普通历史中。已完成列表任务会清除对应检查点。浏览器本地存储可能在普通与无痕窗口之间共享；本扩展不承诺无痕下载不留下本地历史或任务记录。

扩展会使用您浏览器中 B 站的登录 Cookie（若已登录），以便获取与您账号权限一致的可播放清晰度。Cookie 仅用于向 B 站官方接口发起请求，不会被上传至开发者或任何第三方服务器。

3. 权限用途

  • activeTab / scripting：在当前 B 站视频页读取视频信息并执行下载相关脚本
  • storage：在浏览器本地保存历史、设置和未完成任务
  • downloads：保存媒体与封面、查询或取消本扩展的下载，以及显示下载文件
  • clipboardWrite：在您点击复制诊断时写入剪贴板；诊断隐藏媒体链接和敏感参数，请分享前检查内容
  • power：Chrome/Edge 活动下载期间防止系统空闲休眠
  • bilibili.com / bilivideo.com / bilivideo.cn / hdslb.com：访问 B 站页面、视频 CDN 和封面资源，完成您主动发起的下载

4. 远程代码

本扩展为 Manifest V3，不加载、不执行任何远程托管代码。所有脚本均包含在扩展安装包内。

5. 数据共享

我们不会与第三方共享用户数据，因为我们不收集用户数据。

6. 合规使用

本扩展仅供个人学习与研究。请勿用于侵犯版权、绕过付费内容或违反哔哩哔哩用户协议的行为。用户应自行对下载与使用内容负责。

7. 政策变更

若本政策更新，将在本页面修改「最后更新」日期。重大变更时，我们可能通过扩展更新说明或商店页面告知。
