# B站视频下载助手 — 功能与能力说明

> 平台：Microsoft Edge / Google Chrome（Manifest V3）
> 用于保存当前账号有权访问的 B 站视频、音频或封面，仅供个人学习使用。

---

## 1. 产品概述

**B站视频下载助手**是一款浏览器扩展。打开 B 站普通视频页后，可点击浏览器工具栏中的下载助手图标打开面板选择清晰度和格式；进入 `/list/` 页面后，可在「单视频 / 列表下载」两个标签之间切换。视频轨和音频轨可在浏览器内合并为可直接播放的 **MP4**；合成默认在专用 Worker 分段执行，合成阶段仍可取消任务或关闭面板。

- 完全免费，无内购、无激活码
- 不收集、不上传任何用户数据
- 界面以中文为主（`zh_CN`）

---

## 2. 核心能力一览

| 能力 | 说明 |
|------|------|
| 视频页识别 | 自动识别当前打开的 BV / av 普通视频 |
| 信息展示 | 封面、标题、UP 主、分 P、可用清晰度等 |
| 清晰度选择 | 按接口真实可用档位展示；记忆“所选”或“始终最高可用”策略 |
| 格式选择 | MP4 视频 / M4A 音频（仅声音，体积更小） |
| 单集下载 | 选定清晰度后下载；下载中可再点「再下一个」并行启动（最多 3 路） |
| 分 P 队列 | 同一 BV 多 P 按设置并行下载（默认 3 项）；网络失败自动重试 1 次，保存失败停止领取新任务；可「取消整队」；失败短提示 |
| 按章节下载 | 在普通视频的「单视频」面板中手动开启，可跨分 P 勾选播放器章节，每章输出一个 MP4 |
| 列表下载 | 支持 `/list/…`、视频页合集、UP 主空间投稿和合集详情、官方剧集选集；按设置的并发数下载所选条目 |
| 任务中心 | 查看下载中、完成、失败、取消任务。站内切到单视频页后，仍可在任务中心重试切页前失败的列表任务。通过浏览器下载的完成项可打开浏览器下载内容 |
| 诊断日志 | 保留最近 100 条关键日志；一键复制时隐藏媒体地址与敏感参数，并列出任务阶段耗时 |
| 封面下载 | 单独保存当前视频封面；自动升级为 HTTPS 并生成安全文件名 |
| 文件名模板 | 支持预设、自定义、预览和非法字符清理 |
| 下载历史 | 记录最近 50 条；同集 MP4 与 M4A 可并列；同格式去重；可跳回重下 |
| 会话缓存 | 同 URL + 分 P 约 10 秒内重复开面板复用信息，减少请求 |
| 进度反馈 | 每个任务独立进度卡（百分比 + 阶段文字） |
| 防休眠 | Chrome／Edge 活动下载期间阻止空闲休眠，全部暂停或结束后释放；屏幕可正常熄灭 |
| 下载控制 | 每个任务可单独暂停 / 继续 / 取消；分 P 队列可整队取消 |
| 体积预估 | 下载前展示预计大小（以接口估算为准） |
| 登录提示 | 未登录或权限不足时给出清晰度相关提示 |

## 3. 功能详解

### 3.1 适用页面

**支持**

- `https://www.bilibili.com/video/BV…`
- `https://www.bilibili.com/video/av…`
- 对应移动站 `m.bilibili.com/video/…`
- `https://www.bilibili.com/list/…`
- `https://bilibili.com/list/…`
- 普通视频页右侧的合集，可在面板中打开「列表下载」勾选条目
- UP 主空间首页、投稿页（`/upload/video`）及合集详情页
- 官方剧集播放页（`/bangumi/play/ep…`、`/bangumi/play/ss…`，也支持带 `/zh-Hans` 前缀的地址），仅下载 B 站为当前账号返回的可用片源

**不支持**

- 超出当前账号权限、仅供试看、受地区或内容保护限制的媒体

- 分 P 是同一视频中的多段，使用「队列下载全部」按 P 保存。
- 打开合集或 `/list/` 页的下载面板时，默认显示「列表下载」。可切换到「单视频」下载当前视频。
- 在 Chrome 的支持页面点击工具栏扩展图标，即可直接打开完整下载面板。页面未就绪时，可从弹窗刷新页面。

### 3.2 下载与合并

- 从 B 站播放相关接口获取流地址（与页面播放同源环境，避免 CDN 403）
- 高清多为 DASH：分别拉取视频轨、音频轨，浏览器内合并为 MP4
- 低清可能为整段流（durl），直接保存
- 输出格式：**MP4**（视频）或 **M4A**（仅音频，取 DASH 音频轨直接保存，不转码）
- 在 Chrome 或 Edge 点击单视频的「开始下载」或重试时，先选择保存文件夹。确认后开始下载，取消选择则返回面板。文件名按模板生成，同名文件自动追加序号。

### 3.3 清晰度

- 选项来自接口真实返回，不编造「假 1080P / 4K」
- 更高清晰度通常需要登录或具备相应账号权限
- 面板以胶囊按钮展示可选档位，并显示预计体积说明
- 新视频提供普通 1080P 高清时，首次加载预选该档。手动切换后，重开同一视频的面板会保留当前选择。
- 可选择“使用所选清晰度”或“始终最高可用”；后者会按每个视频实际可用档位选择最高项
- 同一清晰度可选择“高码率优先”或“兼容优先”（优先 AVC），不转码。此偏好本地记忆，任务入队时固定。

### 3.4 下载过程控制

| 操作 | 行为 |
|------|------|
| 暂停 | 中断当前网络请求，保留已下载字节 |
| 继续 | 使用 HTTP Range 断点续传 |
| 取消 | 中止任务并重置下载状态 |
| 合并中 | 在专用 Worker 中执行，显示已处理体积与预计剩余时间；此阶段不提供暂停，但可取消任务或关闭面板 |

DASH 场景下，页面可并行拉取音视频，界面按视频流、音频流、合成等阶段显示进度。

### 3.5 分 P 队列

- 当视频有多个传统分 P（`pages`）时，显示「队列下载全部分 P」
- 按 P1 → P2 → … 的顺序安排任务，同时处理 1–5 项（默认 3 项），有空位后自动开始下一项，并汇总成功数量
- 在 Chrome 点击「队列下载全部分 P」后，为本批选一次保存文件夹。取消目录选择会返回面板。重试未完成项时，可为重试批次重新选目录。
- 每张列表任务卡分别显示本批次序号与总数（如「正在下载 3/51」），以及该任务的已下载 / 总大小；重试时显示本次重试队列的序号，文件命名编号保持不变。
- 下载阶段可「暂停全部」；暂停后按钮变为「继续全部」，恢复活动任务并继续安排队列
- 某一 P 失败时自动等待约 1 秒再重试 1 次（仅网络失败；保存失败、扩展连接异常及用户取消不自动重试）
- 队列进行中可点「取消整队」：停止后续分 P，并取消进行中的任务；未完成项可通过重试继续，已保存内容不会重新下载
- 音视频合成阶段无法安全暂停，按钮会提示等待合成完成或取消整队
- 与「再下一个」并行下载互斥：并行未结束时请先完成再开分 P 队列
- 单 P 视频不显示队列按钮

#### 按章节下载

- 在普通视频的「单视频」面板中勾选「按章节下载」。它默认关闭，刷新页面或切换到另一投稿后会关闭。同一投稿内切换分 P 时保留已勾选的章节。
- 每个分 P 显示播放器提供的章节标题和起止时间。选择所需章节，留空「跳过」等填充章节，也可以对单个 P 全选或清空。读取失败可以在对应 P 重试。
- 点击「下载所选章节」后为整批选择一次保存目录，每章输出一个 MP4。文件名追加分 P 和章节编号及标题，例如 `视频名称 - P02-03 第21–22集.mp4`。一个章节包含多集时，这些集会保存在同一个文件里。
- 章节下载需要支持字节范围请求的 DASH 片源。扩展会跳过未选章节的主体，仅额外读取裁切附近解码需要的片段。暂停、取消和重试可使用现有队列控件。

### 3.6 列表、合集与空间批量下载

- 设置中的「批量同时下载数量」可选 1–5，默认 3；调整后从下一批生效。每个条目的视频、音频和封面占用同一个任务名额，合成仍按设备资源保护规则排队。
- 列表批量和整 P 队列的文件自动追加 `_p1`、`_p2` 等后缀，例如 `视频名称_p1.mp4`。编号按本次选中任务的排列固定，与下载完成顺序无关；只选原列表第 3、7 项时使用 p1、p2。同条目的音频和封面共用编号；失败重试保留首次编号。

- `/list/…` 页面可切换「单视频」与「列表下载」。长列表可先滚动 B 站页面再重新进入「列表下载」，也可在面板有「继续加载」入口时读取更多条目。
- 视频页合集由 B 站提供合集条目，面板会展开条目中的分 P。UP 主空间首页与投稿页的「下载全部」会分页读取并全选公开视频投稿，多分 P 投稿在这个入口下载第一 P。
- 从空间投稿任意分页进入「读取全部投稿」都会从 API 第 1 页开始。未完成任务会保留入队时的清晰度策略及档位，切页或刷新后重试沿用；已解析出片源的任务保留实际档位。
- 已加载的可用条目可逐项勾选，也可全选或取消全选。每次选择数量不限，队列按列表顺序处理选中的条目。
- 列表支持按需选择视频（MP4）、音频（M4A）及封面。官方剧集选集会按所选媒体类型并行检查可用性，最多同时检查 4 项，每项检查完成后间隔 100 毫秒继续检查下一项，结果逐项显示。下载期间暂停启动新的检查，队列结束后自动继续；受限条目会显示相应提示。仅选封面时以封面是否可用为准。
- Chrome 批量下载会将本批选中的视频、音频和封面全部保存到同一文件夹，同名文件自动追加序号。保存失败时会停止批次，保留未完成项供重试，并尝试清理本次保存留下的空文件。批量封面读取超过 30 秒会超时；取消整队或单项任务时会中止封面读取，未完成封面可重试。
- 保持页面打开，便于并行队列继续执行。队列支持暂停、继续、取消整队和重试未完成项；目标清晰度不可用时显示实际档位。

### 3.7 下载历史

- 每次成功下载自动记录（普通/无痕各最近 50 条，本地存储，不上传）
- 在普通网页点击 Chrome 工具栏扩展图标，可从弹窗的「下载历史」查看标题、时间和清晰度或格式。批量文件可在所选目录中找到。
- 点击「打开」跳回对应视频页（自动定位分 P）并自动展开面板，便于重下
- 可一键「清空」
- 多标签页同时完成下载时由后台依次写入历史。新产生的普通与无痕历史分别保存，在对应窗口的弹窗中查看或清空；无痕历史仍保存在浏览器本地。旧版本的历史无法自动区分来源，继续保留在原普通历史中。

### 3.8 其他体验

- 页面不显示悬浮按钮；面板从浏览器工具栏打开，窗口缩放后自动适配可视区域
- 站内切换视频（合集 / 推荐跳转）**即时刷新**面板，无需等待
- 面板「设置」支持自定义文件名模板。模板可使用标题、BV 号、清晰度、UP 主和分 P 等字段，面板提供预览，保存时会清理非法字符。文件名过长时优先缩短标题、分 P 标题和 UP 主名称。任务入队时使用当时的模板。
- 下载历史与按钮位置均存本地（`storage` 权限），**不上传任何数据**
- 合并库按需加载（仅检测到高清 DASH 片源时注入），页面性能开销最小

## 4. 使用入口

### 4.1 下载面板（实际下载在此完成）

入口：浏览器工具栏中的下载助手图标 → 展开面板。

面板大致包含：

1. 视频识别 / 标题信息
2. 封面与 UP 等信息卡片
3. 分 P 列表（多 P 时）
4. 清晰度选择 + 清晰度策略 + 格式选择（MP4 视频 / M4A 音频）
5. 预计大小、登录相关提示
6. 「开始下载」；多 P 时另有「队列下载」
7. 「下载封面」
8. 下载中的进度区（阶段、百分比、进度条、暂停 / 取消）
9. 底栏保留设置入口；本地任务与诊断功能保留。

提供列表下载的播放页可使用双标签：

- **单视频**：与普通视频页一致，下载当前展示的视频或封面
- **列表下载**：选择内容类型和已加载条目，下载视频时可选清晰度。开始后可查看队列进度或整队取消。

### 4.2 工具栏图标

- **Chrome 支持的 B 站页面**直接展开当前视频或列表的下载面板。
- **普通网页**显示支持页面说明和「下载历史」。历史中的「打开」可跳回对应视频或分 P，并展开面板。
- **页面未就绪**时，弹窗提供「刷新并重试」。

## 5. 界面与体验

- 面板和弹窗支持切换主题与界面语言
- 加载时有骨架屏，减少空白等待感
- 失败时给出简短状态文案，下载失败后可重试。
- Chrome／Edge 在下载准备、传输、合成和保存期间自动阻止空闲休眠，屏幕仍可熄灭。所有任务结束或全部暂停且无合成、保存进行时恢复正常休眠。关闭面板不影响保护。
- 防休眠不阻止手动休眠、合盖或关机。
- 列表页的两个标签共用稳定面板外框；视频清单、单视频任务和列表任务各自按空间滚动
- 面板通过右上角 X 关闭；关闭后下载继续，再次点击工具栏图标可查看当前任务，页面不保留悬浮入口

## 6. 隐私与合规

| 项目 | 说明 |
|------|------|
| 数据收集 | 不收集、不上传浏览记录、账号或下载内容 |
| 权限 | `activeTab`、`scripting`、`storage`、`downloads`、`clipboardWrite`，Chromium 另使用 `power` 防止下载期间空闲休眠。主机权限见 [manifest.json](../manifest.json)。 |
| 用途声明 | 个人学习备份；请遵守 B 站用户协议与版权法规 |
| 访问限制 | 遵循 B 站对当前账号、地区及内容的访问限制 |

## 7. 能力边界（明确不做）

以下能力**当前版本不提供**，避免与已有功能混淆：

- 字幕、弹幕导出
- 固定的全局输出目录设置（Chrome/Edge 每次下载或每批选择文件夹）
- 账号体系、云同步

## 8. 技术能力摘要（给开发者）

| 要点 | 说明 |
|------|------|
| 架构 | MV3。页面代理在 MAIN world 请求 API 和 CDN，内容脚本在 ISOLATED world 管理面板、合成调度及保存。 |
| 为何 MAIN | 扩展后台直连 CDN 易 403，须与页面共享 Cookie / Referer |
| 合并 | `mp4-remux`（MIT）将 DASH 音视频封装为 MP4 |
| 通信 | 页内 `postMessage`；popup ↔ content 用 `chrome.runtime` |
| 电源管理 | 内容脚本报告任务需求，后台聚合多个页面和原生保存任务，仅在活动期间申请系统级防休眠 |

更完整的架构与组件规范见[开发指南](DEVELOPER.md)，本地调试与打包见[开发与验证](开发与验证.md)。

## 9. 快速开始

1. 打开 `edge://extensions` 或 `chrome://extensions`
2. 开启「开发者模式」→「加载解压缩的扩展」→ 选择本扩展目录
3. 打开任意 B 站普通视频页或 `/list/` 列表页
4. 点击浏览器工具栏中的下载助手图标 → 选择下载模式和清晰度 → 开始下载
