# bilibili-helper

一款面向 Microsoft Edge 和 Google Chrome 的 B 站下载扩展，可保存当前账号有权访问的视频、音频和封面。

本项目基于 [snowflake-hangdudu](https://github.com/snowflake-hangdudu) 开发的 [B站bilibili下载助手](https://github.com/snowflake-hangdudu/bili-downloader) 二次开发。感谢原作者的开发与分享。

## 原有功能

- **单视频下载**　打开 B 站普通视频页，选择可用清晰度，保存为 MP4 视频或 M4A 音频，也可以单独下载封面。
- **批量下载**　可将同一视频的多个分 P 加入队列，也可从 B 站列表、视频合集和 UP 主空间投稿中选择要下载的条目。
- **任务管理**　查看下载进度，暂停、继续或取消任务，失败后可重试。
- **文件名与历史**　支持自定义文件名模板，下载历史保存在本地，可从历史记录返回原视频。

## 本项目的改进

- **一次保存**　每批只需选择一次保存文件夹，本批文件会自动保存到该目录。
- **批量并发**　分 P 队列和列表批量下载可同时处理 1–5 个任务，默认 3 个。有空位时，队列会自动开始下一项。
- **操作优化**　点击浏览器工具栏的扩展图标打开下载面板。在支持的页面，可切换「单视频」和「列表下载」，勾选条目后开始下载，并在同一面板查看进度或重试。

## 快速开始

1. 在 Edge 打开 `edge://extensions`，或在 Chrome 打开 `chrome://extensions`。开启「开发者模式」，点击「加载解压缩的扩展」，选择包含 `manifest.json` 的项目根目录。
2. 打开 B 站视频页、列表页或 UP 主空间投稿页，点击浏览器工具栏中的扩展图标。
3. 在面板中选择要下载的内容并开始下载。批量下载时，选择一次保存文件夹即可。

更多操作和支持范围见 [功能说明](docs/功能说明.md)。
